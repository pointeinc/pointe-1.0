# Pointe Construction Website 2.2

## Uploading to GitHub Pages

Upload **all files and the entire `assets` folder** to the top level of your GitHub repository.

The repository should show:

- `index.html`
- `work.html`
- `process.html`
- `story.html`
- `contact.html`
- `styles.css`
- `script.js`
- `assets/`

Do not upload the outer `pointe-construction-2.2` folder itself.

After committing the files, wait 1–3 minutes and hard-refresh the live site with `Ctrl + Shift + R`.

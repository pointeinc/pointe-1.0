# Pointe Construction 2.0

A responsive, multi-page static website that can be deployed directly from GitHub.

## Pages
- `index.html`
- `work.html`
- `process.html`
- `story.html`
- `contact.html`

## Deploy to the existing GitHub repository
1. Back up or remove the current repository contents.
2. Upload **all files and the `assets` folder** from this package to the repository root.
3. Commit the changes.
4. Your connected hosting service should redeploy automatically.

## Items to replace before final launch
- The current house and craftsmanship images are temporary visual concept images. Replace the files in `assets` using the same filenames to update them everywhere without editing code.
- Confirm the business email in `contact.html` and `script.js`.
- Add a public phone number when ready.
- Replace the email-based contact form with Formspree, Netlify Forms, or another hosted form endpoint.
- Add real project pages and photography as they become available.

## Image replacement sizes
- `hero.jpg`: 1920 × 1080 or larger
- `cta.jpg`: 1920 × 700 or larger
- `work-1.jpg` through `work-3.jpg`: 1200 × 800 or larger
- `detail-1.jpg` through `detail-3.jpg`: square images, at least 900 × 900
- `craft.jpg`: landscape, at least 1400 × 760
